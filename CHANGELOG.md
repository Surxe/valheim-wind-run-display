# Changelog

## 1.0.0

- First release, for Valheim 1.0 (Deep North).
- Live Wind run value under the status effect icon, default `Speed: +18%`.
- Configurable lines (`RunSpeed`, `RunStamina`, `Wind`), their order and labels, and an
  optional fixed font size.
- Wind run max/current values added to the status effect tooltip.
